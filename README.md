# 🌲 Mental Wellness — Mental Health Score Prediction

A calm, nature-inspired web app that estimates a mental health score from lifestyle and social-media usage data, using a machine learning model served through FastAPI.

**🔗 Live demo:** [https://mental-health-scorer-1-0kf6.onrender.com/](https://mental-health-scorer-1-0kf6.onrender.com/)

> ⚠️ This prediction is generated by a machine learning model and is intended for educational and informational purposes only. It is not a medical diagnosis and should not replace professional mental health advice.

---

## ✨ Overview

Users answer a short questionnaire about their age, lifestyle, and social-media habits. The form sends this data to a FastAPI backend, where a trained ML model predicts a mental health score, which is then displayed in a calming, nature-themed result view.

## 💻 Running Locally

### 1. Clone the repo

```bash
git clone <https://github.com/sarweshasiddheshwar/Mental-Health-Scorer.git>
```

### 2. Install backend requirements

```bash
pip install -r requirements.txt
```

*(or manually: `pip install fastapi uvicorn pandas scikit-learn joblib`)*

### 3. Start the server

```bash
python -m uvicorn main:app --reload --port 8000
```

### 4. Open the app

Visit:

```text
http://127.0.0.1:8000
```

The backend serves the frontend directly, so there's nothing else to run.

## 🔌 API Reference

**Endpoint:** `POST /predict`

**Request body:**

```json
{
  "age": 21,
  "gender": "Male",
  "country": "India",
  "academic_level": "Undergraduate",
  "most_used_platform": "Instagram",
  "purpose_of_use": "Education",
  "avg_daily_usage_hours": 4.0,
  "daily_unlocks": 60,
  "study_hours": 3.0,
  "physical_activity_hours": 1.0,
  "sleep_hours_per_night": 7.0,
  "stress_level": "Medium"
}
```

**Response body:**

```json
{
  "predicted_mental_health_score": 78.4
}
```

Interactive API docs (Swagger UI) are available at:
**[https://mental-health-scorer-1-0kf6.onrender.com/docs](https://mental-health-scorer-1-0kf6.onrender.com/docs)**
